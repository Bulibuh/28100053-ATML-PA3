# Sources and assistance

- **Assignment specification:** supplied `ATML-PA3.pdf`, Task 1. The recipes, projection equations, benchmark protocol, and diagnostic definitions follow that manual.
- **Qualitative inputs:** `configs/first_plot_questions.yaml` is the exact user-supplied file, retained without edits. Its original authors' embedded metadata is preserved; the implementation does not call the named remote judge.
- **Model:** [Qwen/Qwen3-0.6B](https://huggingface.co/Qwen/Qwen3-0.6B), using the model's own chat template and an immutable revision recorded during preparation.
- **Datasets:** [MetaMathQA](https://huggingface.co/datasets/meta-math/MetaMathQA), [GSM8K](https://huggingface.co/datasets/openai/gsm8k), [HellaSwag](https://huggingface.co/datasets/Rowan/hellaswag), [SuperGLUE/BoolQ](https://huggingface.co/datasets/aps/super_glue), and [ARC](https://huggingface.co/datasets/allenai/ai2_arc). Check their source licenses and cite their papers in your own submission.
- **Evaluation implementation and task definitions:** [EleutherAI lm-evaluation-harness](https://github.com/EleutherAI/lm-evaluation-harness), version 0.4.9. This project calls its stock task prompts, likelihood scoring, generation stopping rules, answer filters, and metrics. Harness-source hashes and dataset revisions are recorded by preparation.
- **Libraries:** PyTorch, Hugging Face Transformers/Datasets/Accelerate/Hub, NumPy, pandas, Matplotlib, PyYAML, and pytest. PEFT is installed for the harness/Transformers integration; the training adapters here are implemented directly from the assignment equations, not through PEFT.
- **Methods:** Hu et al., *LoRA: Low-Rank Adaptation of Large Language Models*; Li et al., *Explicit Inductive Bias for Transfer Learning with Convolutional Networks* (L2-SP); Xiong and Xie, *OPLoRA*, the required reading named by the manual.
- **Coding assistance:** OpenAI Codex assisted with implementation and tests. Portions of the training, evaluation, and setup utilities were adapted and corrected from this repository's earlier implementation at commit `12260c3`; Tasks 2 and 3 were not restored. No training results or report analysis were generated as part of this implementation.
